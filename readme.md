# CleanChatGPT

清理 macOS 上 ChatGPT / Codex **默认位置**的数据。单文件 zsh 脚本，不需要 Python 或另外安装依赖，不读取或解析应用配置。

默认只预览；显式使用 `--apply` 才会直接删除。**不备份、不移入废纸篓、没有自动回滚。** 默认配置文件删除后由应用重新生成；配置中曾指向的自定义数据位置不在清理范围内。

## 使用

使用 macOS 自带的 `/bin/zsh`，以当前普通用户执行，不要 `sudo` 或 `source`。实际清理前退出 ChatGPT、Codex、相关 CLI 及其他写入程序；脚本会检查相关进程，不会强制结束它们。

以下是使用示例，不表示已经执行过这些操作：

```sh
# 只读预览
./clean-chatgpt-codex.sh

# 实际清理，需要输入 DELETE 确认
./clean-chatgpt-codex.sh --apply

# 预览时另外保留某个目录；实际执行时应使用相同保护参数
./clean-chatgpt-codex.sh --dry-run --protect "$HOME/.codex/sessions"
```

| 参数 | 作用 |
| --- | --- |
| 无参数 / `--dry-run` | 只显示计划和保留原因。 |
| `--apply` | 按固定清单直接清理，不备份。 |
| `--yes` | 仅配合 `--apply`，跳过 `DELETE` 确认。 |
| `--protect PATH` | 保留该绝对路径；含它的候选目录也整项跳过。可重复。 |
| `--remove-apps` | 另外纳入 `/Applications`、`~/Applications` 中已核对 bundle ID 的已知应用包。 |
| `--no-open` | 兼容旧参数；脚本始终不自动打开网页。 |
| `--help` | 显示帮助。 |

## 默认清单

- `~/.codex`、`~/.config/codex` 中已知的状态文件和默认配置，包括 `config.toml`、认证、历史、数据库、日志和缓存。未知根项不纳入；`*.config.toml` 只按名称登记，不读取其内容。
- 会话仅匹配 `rollout-*.jsonl`，日志、数据库及 shell 快照也仅匹配已知文件名，保留同目录中的其他文件。
- 已识别的插件下载缓存和导入缓存。
- `~/Library` 下已知 ChatGPT/Codex 应用标识对应的支持数据、缓存、日志、偏好、Cookie、容器、窗口状态、诊断报告及提示音。
- 系统提供的当前用户默认缓存／临时目录中的应用专属子目录。
- `~/Documents/ChatGPT`、`~/Documents/Codex` 根层的 `.DS_Store`、`.localized`；用户文件和项目子目录全部保留。

配置文件本身会删除，其中内嵌的自定义指令也会删除。希望留下它时，用 `--protect` 明确指定。脚本不使用 `CODEX_HOME`、`CODEX_SQLITE_HOME` 等覆盖值，也不提供自定义根目录／日志目录／数据库目录的发现参数。

## 工作文件保护

自定义技能、规则、工作树、生成图片、附件、可视化、宠物和未知根项不在 Codex 默认状态名单中。共享的 `~/.agents` 也会保留。

若某个候选目录含 Git 标记或已知工作目录名，**整个候选目录跳过**，不再拆分处理。这可能留下同目录内的缓存，预览会显示保留原因。`--protect` 指向候选内部时，也按同一规则整项保留。

候选根或路径组件为软链接时保留；不跟随目录内部的链接扩大范围，不跨挂载点清理。状态目录和文稿根目录只有确实为空时才移除。无法检查目录时停止，不能把读取失败当成已经清空。

保护依赖已知位置、目录名和 Git 标记。如果手工把工作文件放在普通缓存或临时目录中，请用 `--protect` 保留；脚本无法判断任意文件的实际用途。应先退出所有写入程序，避免清理过程中又出现新的工作内容。

## 怎么读代码

[clean-chatgpt-codex.sh](clean-chatgpt-codex.sh) 已按顺序分成四个阶段，并添加中文注释：

1. **参数和账号**：默认只预览，核对当前用户主目录。
2. **固定默认清单**：`add_codex_defaults` 登记状态名称，`add_default` 登记实际存在的路径。
3. **保护和预览**：`should_keep` 检查额外保护、Git、工作目录和软链接，列出保留原因。
4. **确认和清理**：只有 `--apply` 才进入；再次检查进程和保护，再清理清单，最后仅移除空目录。

不需要理解配置解析器、校验快照或恢复清单：本版没有这些机制。

## 验证和边界

已通过 zsh 语法检查，以及在 macOS 禁写沙盒中的 `--help`、默认 `--dry-run` 检查。测试进程禁止写入或删除真实文件，也禁止联网。**没有传入 `--apply`，没有执行删除或做删除测试。** 本机无法读取的 Cookie 路径会列为未确认项；只读预览通过不代表已经验证真实清理效果。

本地清理不能证明云端、钥匙串、个人浏览器、其他设备或系统备份都已清空，也不能保证“从未安装过”。官方手工检查说明见 [CLEANUP-NOTES.md](CLEANUP-NOTES.md)，其中保留文档核对日期及适用范围。
